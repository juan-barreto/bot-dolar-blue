# Bot Dólar 🤖

## ¿Qué hace?
Consulta el precio del dólar blue,oficial,cripto y tarjeta en tiempo real y lo guarda en una base de datos local.

## Tecnologías
- Python
- requests
- SQLite
- python-telegram-bot

## Comandos disponibles
- `/dolar` → devuelve el precio actual del blue
- `/oficial` → devuelve el precio actual del oficial
- `/cripto` → devuelve el precio actual del cripto
- `/tarjeta` → devuelve el precio actual del tarjeta
